## 5 周排期里反复出现的设计纪律

写在这里作为 v0.2+ 的执行参考——5 周里每件大事都触到了同样的纪律边界:

1. **不为扩展件预留 stub**（v0.1 spec Out of Scope #2）——A 类必不装 Worktrees / Plugins / Sub-agents 三件,不在 spec / 脚本 / config 里预留空壳

3. **薄骨架原则**（text-target 协议评审反馈）——parser 留在命令字符串内,不提为骨架件
4. **ADR 只记已决事项,use-case 沉淀待定问题**（ab96750e §保留 2）——v0.2 探索性产物归位 use-cases,不抢 ADR 的位置
5. **复用 v0.1 已落件,不另起 CI / 工具栈**（meta_check.sh 评审反馈）——meta 两维 hard 复用 pytest / iter.sh / templates 已测过的资产,shell + grep 足够
