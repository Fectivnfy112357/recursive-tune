## 实施期踩坑（避坑笔记）

1. **hermes 在 PATH 不可用**：Windows 安装是 .bat wrapper + .exe 子进程,`which hermes` 找不到 → 必须用绝对路径调 hermes.exe
2. **state dir busy 不能 rm**：被 cancel 的 wall_clock 进程残留文件 fd → 重建新 target 目录(v2)
3. **Bash tool timeout 截断整 6 runs**：单 Bash 120s/600s timeout 不够 6×LLM → 拆 atomic per-run
4. **`_noop_ratchet` 不接受参数**：最初定义 `def _noop_ratchet(): pass` 但 `_ratchet_wrapper` 调 `ratchet_fn(target_repo)` → TypeError → 改成 `def _noop_ratchet(target_repo=None): pass`
5. **`_clear_state` 引用不存在的函数名**：`subprocess_rm` 写错成未定义名 → 改名 `_subprocess_rm` 修
6. **hermes 模型是中文**:真 LLM 把英文 README 翻译成中文而非西班牙文等 — D4 glossary 仍通过(关键词在译文文本里),无需 prompt 限定目标语言(留给 T2c / T3 评估)
