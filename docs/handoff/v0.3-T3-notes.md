## 决策（实施期拍板）

### 1. scan_violations 豁免规则
禁词定义本身在 `scan_violations.py` 内, 必须豁免; 测试断言行故意含禁词作参数 → 豁免规则:
- 文件名 `scan_violations.py` / `test_t3_guards.py` 整文件跳过（白名单）
- 行以 `#` / `"""` / `//` 开头 → 跳过（comment）
- 行以 `assert ` 开头 → 跳过（测试断言）
- 行含 `--resume` / `--restore-cwd` / `--no-restore-cwd` hermes CLI 参数 → 跳过（hermes 内部 session resume ≠ v0.3 spec 锁的「断点续跑」语义）

实施期踩坑 1: 初版无豁免 → 扫到自己和 test 文件, 误命中 17 处。 修豁免后 0 命中。

### 2. 不扫 hermes CLI 参数
