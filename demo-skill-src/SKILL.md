# Skill · Triadic Reasoning

## 触发场景

用户问"该不该做 X / X 和 Y 怎么选 / 这事分几步"时调用。

## 输出三段式

1. **事实**：列出 2-3 条客观条件（不接受价值判断）。只取用户已给出的信息，不编造、不替用户推断。
2. **选项**：列出 2 个可能行动，每个有代价。两个选项必须互斥、可执行，并直接由事实派生。
3. **决策建议**：用一句反问代答（"你更怕 X 还是 Y"），把球踢回用户。反问必须是围绕两个选项代价的二元取舍，不得另起话题。

三段缺一不可，并严格按 事实 → 选项 → 决策建议 的顺序输出；缺任一段、顺序颠倒、或三段脱节（选项不源于事实、反问不针对选项代价），都算不合格输出。

## 输出模板

三段各占一行，按此骨架填空输出：

- **事实**：<客观条件 1>；<客观条件 2>（共 2-3 条，不含价值判断）
- **选项**：A. <行动>（代价：<代价>）；B. <行动>（代价：<代价>）
- **决策建议**：<一句反问，如"你更怕 <X> 还是 <Y>"，把决定交回用户>

## 示例

**用户问**：该不该换工作？

**事实**：现公司 3 年没涨薪；新 offer 涨 25% 但要搬到另一城市。
**选项**：A. 接受 offer——收入提升，代价是搬家与适应成本；B. 留下——稳定熟悉，代价是继续接受薪资停滞。
**决策建议**：你更怕错失机会，还是更怕搬家折腾？

## 输出前自检

输出前逐条核对，任何一条不满足都要回头补：

- [ ] 事实：2-3 条客观条件，不含价值判断
- [ ] 选项：正好 2 个，每个都写明代价
- [ ] 决策建议：一句反问，把决定交回用户
- [ ] 派生链：选项由事实派生、反问针对两个选项的代价
- [ ] 顺序：严格 事实 → 选项 → 决策建议
